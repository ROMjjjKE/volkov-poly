# Волков Владимир — устройство пола

Ламинат, кварц-винил, линолеум, дерево и ОСБ. Основание, укладка, плинтус. Телефон +375 44 763-11-74.

**Живой сайт:** https://romjjjke.github.io/volkov-poly/

## Что внутри

- Техническая легенда в герое: пять покрытий, основание, допустимый перепад, зазор, кто работает.
- Матрица покрытий: пять позиций × четыре условия. Чипы «тёплый пол / влага / животные / бюджет»
  фильтруют таблицу, несовместимые строки гаснут, счётчик показывает «подходят N из 5».
- Пин-сцена «пирог пола»: шесть слоёв в изометрии, плоскости расходятся по оси, подписи с толщинами
  в мм загораются по очереди. На мобильном сцена статична, все подписи видны.
- Основание (демонтаж, стяжка, фанера и ОСБ, выравнивание, влажность), шесть правил укладки,
  FAQ, форма заявки в WhatsApp.

## Стек

React + Vite + TypeScript, GSAP + ScrollTrigger (лениво, только для пирога), Lenis.
Шрифты самохостингом: Rubik 400/600 + Roboto Mono 400, 58 KB, метрические фолбэки (102,9% и 100%).
Изображений нет: разрез и интерфейс собраны из блоков, линий и градиентов.

## Ограничения

Города в исходных данных не было: на сайте нет ни Минска, ни другой привязки, выезд подтверждается
по телефону после адреса. Цен нет — заказчик не дал ни прайса, ни вилки, поэтому везде «назову цену
за метр после метража и адреса». Вердикты в матрице — профессиональный ориентир по свойствам
материалов, а не замена осмотру; это прямо написано под таблицей. Толщины слоёв в разрезе — типовые
диапазоны, а не проект конкретного пола.
